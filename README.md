# Claude Artifacts

Claude artifacts by [Stephanie Schwarz](https://linkedin.com/in/uxschwarz) — UX writing and content design tools that run inside Claude.

## How to use

Claude doesn't support sharing artifacts directly between accounts. To use any of these tools in your own Claude:

1. Download the `.html` file.
2. Open a new conversation in Claude and attach the file.
3. Ask Claude: *"Publish this HTML file as an artifact, without changing the code, and declare the sample capability."*
4. Open the published artifact. The first time you use a feature that calls Claude, you'll be asked to allow it — accept.

> These files contain no API key. Every request uses the Claude account of whoever is running the tool, counting toward that person's own usage limit. You need to be signed in to Claude for the AI features to work.

## Artifacts

### [Gerador de microcópias para UX](gerador-microcopias-ux.html)
**UX Microcopy Generator · v2 · PT/EN**

Generates UX microcopy for buttons, errors, empty states, loading messages, and more. Supports Portuguese and English. Lets you save your own writing guidelines for consistent results.

Localized and developed by Stephanie Schwarz. Inspired by the English version created by [María Alvear](https://linkedin.com/in/alejaalvear).

---

### [Human Translator](human-translator.html)
**PT ↔ EN Translation · PT/EN**

Translates between Portuguese and English in a way that sounds human — not like a machine translator. Lets you adjust tone and style, and also offers grammar correction.

---

### [UX Copy A11Y](ux-copy-a11y.html)
**Accessibility Content Toolkit · v2 · PT/EN**

Audits UX copy for accessibility compliance against the EAA (European Accessibility Act) and WCAG 2.2. Flags issues and generates compliant alternatives. Covers error messages, empty states, CTAs, form labels, alt text, and more.

---

### [UX Copy Toolkit](ux-copy-toolkit.html)
**Audit & Create Accessible UX Copy · v3 · PT/EN**

A more complete toolkit for auditing and generating accessible UX copy. Combines content review, compliance checking, and copy creation in one interface.
